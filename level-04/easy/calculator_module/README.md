# Q1: Calculator Module

Create a calculator module with basic and advanced mathematical operations.

## Requirements

Create a `calculator.py` module containing the following functions:

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`
- `divide(a, b)`
- `power(a, b)`
- `sqrt(a)`

Each function should:

- Accept the required arguments
- Return the calculated result
- Include an appropriate docstring

Handle the following errors:

- Division by zero
- Square root of a negative number

Create a main program that:

- Imports the calculator module
- Allows the user to perform calculations
- Displays the results
- Continues running until the user chooses to quit
