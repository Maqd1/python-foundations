# E-Commerce System with Discounts

A Python OOP e-commerce system demonstrating products, shopping carts, discount strategies, inventory management, and order processing.

## Features

The system supports:

- Product management
- Product inheritance
- Shopping carts
- Adding and removing cart items
- Stock validation
- Inventory reservation
- Low-stock alerts
- Multiple discount strategies
- Combining discounts
- Coupon codes
- Order creation
- Order status tracking
- Invoice generation
- Shipping addresses
