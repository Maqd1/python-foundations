# Shape Hierarchy with Calculators

A Python OOP project that demonstrates an abstract shape hierarchy, polymorphism, dataclasses, collections, and magic methods.

## Features

The program creates and works with:

- Rectangles
- Circles
- Triangles
- Squares
- Ellipses

It can:

- Calculate the area of individual shapes
- Calculate the perimeter of shapes
- Calculate the total area of multiple shapes
- Find the largest shape
- Group shapes by type
- Combine the areas of two shapes
- Sort shapes by area
