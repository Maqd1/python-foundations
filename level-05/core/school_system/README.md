# School Management System

A Python-based school management system designed to demonstrate
object-oriented programming, business logic, software architecture,
testing, and application design.

## Features

- Student, teacher, and administrative staff management
- Course management
- Semester management
- Course registration
- Prerequisite validation
- Schedule conflict detection
- Credit-limit enforcement
- Course capacity and waitlists
- Registration override workflow
- Grade and transcript management
- GPA calculation
- Attendance tracking
- Observer-based registration notifications
- Student academic reports
- PDF report generation
- Repository pattern for student and course storage
- Command-line interface
- Automated tests
