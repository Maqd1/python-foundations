# Employee Management System

An interactive employee management system built with Python and Object-Oriented Programming (OOP).

## Features

The system supports:

- Adding employees
- Removing employees
- Viewing all employees
- Searching employees by name
- Searching employees by department
- Generating department reports
- Calculating total payroll
- Calculating average salary

The system contains a base `Employee` class and four specialized employee classes:
