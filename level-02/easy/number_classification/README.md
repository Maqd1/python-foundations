# Number Classifier

## Easy Level

Write a program that takes an integer input from the user and classifies the number.

### Requirements

The program should print **exactly one** of the following categories:

| Condition                           | Output                                  |
| ----------------------------------- | --------------------------------------- |
| Number is greater than `0` and even | `Positive even number`                  |
| Number is greater than `0` and odd  | `Positive odd number`                   |
| Number is less than `0` and even    | `Negative even number`                  |
| Number is less than `0` and odd     | `Negative odd number`                   |
| Number is exactly `0`               | `Zero is neither positive nor negative` |

### Concepts

* `if / elif / else`
* Modulo operator `%`
* Comparison operators

### Example

```text
Enter a number: 8
Positive even number
```

```text
Enter a number: -7
Negative odd number
```

```text
Enter a number: 0
Zero is neither positive nor negative
```
