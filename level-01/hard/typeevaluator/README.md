# The Dynamic Type Evaluator

## Difficulty

Hard

## Task

Write a program that asks the user for one input.

Store the user's input in a variable called `user_input`.

Without using `if` statements, determine and print:

- Whether the input represents an integer
- Its boolean equivalent
- The length of the input

For example, if the user enters:

```text
123
```

the program should determine that:

- The input represents an integer
- The input is truthy
- The input has 3 characters

If the user enters an empty string, the boolean value should be False.

## Hint

You can use:

- .isdigit() to check whether a string contains only digits
- bool() to obtain the boolean value of a value
- len() to determine the number of characters
- Boolean expressions instead of if statements

## Goal

Practice working with strings, boolean conversion, and built-in functions while solving a problem without conditional statements.
