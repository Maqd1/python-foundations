# The Truth Table Tester

## Difficulty

Hard

## Task

Write a program that asks the user for two boolean values.

The user should enter either:

```text
True
```

or:

```text
False
```

Convert the user's input into boolean values and print:

- A
- B
- A OR B
- NOT A
- Whether A and B are equal

The program must not use if statements.

For example, if the user enters:

- True
- False

The output should represent:

- A: True
- B: False
- A OR B: True
- NOT A: False
- A == B: False

## Goal

Practice boolean logic and converting user input into values that can be used in logical expressions without relying on conditional statements.

## Concepts Tested
- input()
- bool
- String comparison
- Boolean values
- and
- or
- not
- ==
- Boolean expressions
