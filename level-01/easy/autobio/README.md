# The Autobiographer

## Difficulty

Easy

## Task

Write a program that asks the user for their:

- First name
- Last name
- Birth year

Calculate their age, assuming the current year is 2026.

Print:

```text
Your name is [Full Name] and you are [Age] years old.
```

Use an f-string for the final output.

## Concepts Tested

- input() 
- int() 
- f-strings 
- Arithmetic
