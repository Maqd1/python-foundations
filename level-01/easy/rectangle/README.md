# The Rectangle Painter

## Difficulty

Easy

## Task

Write a program that asks for the length and width of a rectangle as floats.

Calculate:

- The area
- The perimeter

Print both results with 2 decimal places.

### Hint

Use an f-string with `.2f` formatting for the results.

For example:

```python
print(f"Area: {area:.2f}")
```

## Concepts Tested
- float()
- Arithmetic operators
- Multiplication
- Addition
- Formatted output
