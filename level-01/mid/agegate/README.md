# The Age Gate

## Difficulty

Mid

## Task

Write a program that asks for the user's age as an integer.

If the user is 18 or older, print:

```text
Access granted. Welcome!
```

If the user is under 18, calculate how many years remain until they turn 18 and print:

```text
Access denied. You need X more years.
```

## Goal

Use if/else conditionals combined with assignment and arithmetic.

## Concepts Tested

- input()
- int()
- if/else
- Comparison operators
- Arithmetic
