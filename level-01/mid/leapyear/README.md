# The Leap Year Detective

## Difficulty

Mid

## Task

A year is a leap year if:

1. It is divisible by 4, AND
2. It is NOT divisible by 100, UNLESS it is also divisible by 400.

Write a program that asks the user for a year as an integer.

Print:

```text
True
```

if it is a leap year, and:

```text
False
```

if it is not.

## Hint

Use:

- The modulo (`%`) operator
- Logical `and`
- Logical `or`

## Goal

Master comparison, modulo, and complex logical conditions.

## Concepts Tested

- `input()`
- `int()`
- Comparison operators
- Modulo (`%`)
- Logical operators
